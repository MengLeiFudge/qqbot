# QQBot 生图

云栖的生图插件通过本机 CPA 的 OpenAI Images 接口生成图片。`生图模型` 和 `生图价格` 展示 CPA 当前注册的图片模型和积分价格。`切换生图模型 模型名` 保存用户偏好。渠道模型必须设置 `image: true`。

- `文生图 提示词` 直接按原文画图。`图生图 提示词` 使用当前附件或引用中的一张原图。`头像生图 [@某人] 提示词` 使用指定人物或发送者的头像。
- `文生竖图2k 提示词` 指定画幅和档位。画幅可填横、竖或动，档位可填 1k、2k 或 4k。默认方图为 4096×4096。
- `生成豆豆眼头像` 使用发送者头像，并行生成韩文 v1、中文 v3 各两张。单次请求扣一笔积分。
- `查看积分` 和 `积分排行` 查询群消息累积的生图积分。全部生成失败、超时或结果既无法保存也无法发送时退回预扣积分。部分成功时交付已有结果。

图片在扣积分前获取并验证。成品保存在业务存储根的 `draw/outputs/YYYYMMDD/`，流程支持 PNG 和 GIF。自然语言生图沿用 MaiBot 的消息 Hook，在图像来源和意图明确时进入同一生成流程。

部署时只由云栖启用积分和生图写入。`[rightcodes]` 填本机 CPA 客户端凭据，实际配置保存在本机。积分存放在业务 SQLite 的 `draw.points`，沿用云栖原余额和模型选择。共享数据目录使用当前实例自己的配置。 [脱敏配置示例](config.example.toml)
