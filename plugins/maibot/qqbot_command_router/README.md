# QQBot 固定指令认领

群固定指令直接发送即可触发。指令开头有 QQ @ 时，只由被 @ 且注册了相应指令的机器人参与。`@全体` 允许所有已注册该指令的账号参与同一次认领。正文中的 @ 仍可作为指令参数，例如 `查看 @群友`。

MaiBot 匹配到本机注册的 QQBot 群固定指令后，执行者立即在本机 SQLite 里认领该条消息。数据库的唯一键决定结果，同一条消息只允许首次认领者进入执行。临时掉线或未注册该指令的账号不会参与。认领随数据库持久保存，新消息可独立认领。

部署清单仅向云栖同步此插件。将 `config.example.toml` 复制为本机 `config.toml` 后填写参与账号和 `database_path` 的绝对路径，再启用插件。云栖目前使用仓库下的 `data/shared/command_claims.sqlite3`。多账号启用前，先核对 [跨账号群消息标识](../napcat_adapter/docs/message-api.md#跨账号群消息标识)，再为参与账号配置同一名单和同一数据库。群消息缺少原始群序号时，单账号模式使用当前账号的消息 ID，多账号模式终止该次认领。各功能自己的权限检查和业务文件路径沿用现有配置。
