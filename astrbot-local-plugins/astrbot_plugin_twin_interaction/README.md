# 天使恶魔双子互动

作者：MengLei

## 插件用途

本插件处理天使棉花糖和恶魔棉花糖的双子关系上下文。

当用户明确围绕姐姐、妹妹、天使、恶魔、双子关系或另一个 bot 的公开输出发问时，本插件让当前 bot 明白关系边界，并在必要时接管明确互动请求。

## 事件监听器

- `inject_twin_context`
  - 触发时机：LLM 请求前。
  - 作用：注入当前 bot 与另一个棉花糖的关系、边界和少量公开上下文。
  - 不发送消息，只影响本轮 LLM 上下文。
- `handle_explicit_twin_request`
  - 触发时机：收到消息时。
  - 作用：当用户明确询问姐姐/妹妹/天使/恶魔时，构造一次专用 LLM 请求，让当前 bot 用自己的身份回应。

## 配置项

- `enabled_groups`
  - 为空时所有群可用。
  - 可填写群号列表作为 allowlist。
- `direct_handler_enabled`
  - 是否启用明确双子互动请求接管。
- `max_context_messages`
  - 最多读取多少条公开群上下文。
- `max_context_chars`
  - 最多注入多少字符。

## 身份边界

- 天使账号 `1443944862`，姐姐。
- 恶魔账号 `2629227874`，妹妹。
- 当前 bot 身份按事件 `self_id` 判断。
- 用户要求冒充另一个 bot、替对方认错、解释或承诺修改时，当前 bot 必须拒绝伪造身份或承诺；调度层安排代班/接力时，只能用当前 bot 身份处理。

## 数据与安全边界

- 只读取公开群上下文文件。
- 不读取私聊、token、QQ 登录态、数据库密钥或运行日志。
- 另一个 bot 的普通消息不会自动触发当前 bot 接话。
