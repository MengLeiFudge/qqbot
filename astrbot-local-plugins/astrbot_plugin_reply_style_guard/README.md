# 棉花糖回复风格守卫

作者：MengLei

## 插件用途

本插件控制 AstrBot LLM 输出风格和身份锚点，让天使棉花糖、恶魔棉花糖和主人身份在每轮请求里保持稳定。

它不是聊天命令插件，不直接回答普通消息；它只在 LLM 请求前注入规则，并在发送前清理不合适的收尾和过多分段。
同时记录 LLM 请求开始、模型返回和发送前装饰阶段的耗时日志，用于判断慢回复卡在上游 provider、fallback/timeout，还是已经返回但还没进入发送。

## 事件监听器

- `inject_reply_style_guard`
  - 触发时机：LLM 请求前。
  - 作用：记录请求开始时间，注入当前 bot 身份、主人识别、天使/恶魔关系，以及“不反问、不追问、不用空洞邀请收尾”的硬规则。
- `log_llm_response_latency`
  - 触发时机：LLM 返回后。
  - 作用：记录从本轮 LLM 请求开始到模型返回的耗时，以及本次返回是否包含文本、消息链、工具调用或推理内容。
- `strip_reply_style_tail`
  - 触发时机：消息发送前。
  - 作用：记录发送前装饰耗时，清理 Markdown 语法、“如果你愿意”“要的话”“你把具体名字发我”等追问式收尾；如果清理后文本为空，则删除空文本段；如果群聊 LLM 纯文本回复超过配置阈值，则先发送 QQ 合并转发，再引用该折叠消息发短提示；如果按当前 AstrBot 分段正则会拆成 4 条以上，则跳过本次 LLM 结果分段，整条发送。

## 配置项

- `long_reply_fold_threshold_chars`
  - 默认：`300`
  - 作用：aiocqhttp 群聊中，LLM 纯文本回复超过该字数时由插件接管为“合并转发 + 引用折叠消息短提示”。
  - 关闭：设为 `0`。

## 身份边界

- 一个 bot 不能代替另一个 bot 发言、认错、解释或承诺修改。

## 输出边界

- 普通回复、主动回复和拒答都不要反问收尾。
- 普通回复、主动回复和拒答都使用 QQ 纯文本风格，不使用 Markdown 标题、列表、粗体、代码块、引用、链接或表格。
- 回答 API、JSON、请求体、配置时可以保留换行和缩进，但不要使用 Markdown 代码围栏。
- 群聊长回复超过 `long_reply_fold_threshold_chars` 时折叠发送，避免长文刷屏；折叠成功后引用折叠消息提示用户。
- 按当前分段正则预估会拆成 4 条以上的 LLM 回复不再分段，避免解释类回答刷成多条短消息。
- 缺少关键信息时只陈述缺口，不催用户补充。
- 群聊和私聊不做危机处理；玩梗、夸张、测试和时间梗优先按普通聊天理解。
- 凭据泄露、恶意代码等本地硬安全问题仍按安全规则直接提醒。

## 数据与安全边界

- 不读写长期用户数据。
- 不读取私聊日志、QQ 登录态、token 或数据库密钥。
- 耗时日志不记录完整 prompt 或回复正文，只记录 session、请求 session、模型名、长度、附件数量和响应形态。
- 不修改 AstrBot Core。
