# 棉花糖回复风格守卫

作者：MengLei

## 插件用途

本插件控制 AstrBot LLM 输出风格和身份锚点，让天使棉花糖、恶魔棉花糖和主人身份在每轮请求里保持稳定。

它不是聊天命令插件，不直接回答普通消息；它只在 LLM 请求前注入规则，并在发送前清理不合适的收尾。

## 事件监听器

- `inject_reply_style_guard`
  - 触发时机：LLM 请求前。
  - 作用：注入当前 bot 身份、主人识别、天使/恶魔关系，以及“不反问、不追问、不用空洞邀请收尾”的硬规则。
- `strip_reply_style_tail`
  - 触发时机：消息发送前。
  - 作用：清理“如果你愿意”“要的话”“你把具体名字发我”等追问式收尾；如果清理后文本为空，则删除空文本段。

## 身份边界

- 天使棉花糖是姐姐，账号 `1443944862`。
- 恶魔棉花糖是妹妹，账号 `2629227874`。
- 主人账号 `605738729`。
- 当前 bot 身份按事件 `self_id` 判断，环境变量只作兜底。
- 一个 bot 不能代替另一个 bot 发言、认错、解释或承诺修改。

## 输出边界

- 普通回复、主动回复和拒答都不要反问收尾。
- 缺少关键信息时只陈述缺口，不催用户补充。
- 群聊和私聊不做危机处理；玩梗、夸张、测试和时间梗优先按普通聊天理解。
- 凭据泄露、恶意代码等本地硬安全问题仍按安全规则直接提醒。

## 数据与安全边界

- 不读写长期用户数据。
- 不读取私聊日志、QQ 登录态、token 或数据库密钥。
- 不修改 AstrBot Core。
