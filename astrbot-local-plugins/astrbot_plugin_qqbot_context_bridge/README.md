# QQBot 群上下文桥接

作者：MengLei

## 插件用途

本插件在 AstrBot 调用 LLM 前，把 NoneBot2 侧已经沉淀的公开群聊上下文注入到本轮请求中。

目标是让 bot2 在迁移阶段延续 bot1 的群聊语境，例如最近群友提到的项目、问题、昵称和公开讨论片段。

## 事件监听器

- `inject_bot1_group_context`
  - 触发时机：LLM 请求前。
  - 作用：按当前群号读取 `data\nonebot2\run\ai\group_context\<群号>.json`，截取少量公开上下文注入本轮请求。
  - 不发送消息，只修改本轮 LLM 上下文。

## 配置项

- `enabled_groups`
  - 为空时表示所有有公开上下文文件的群都允许桥接。
  - 可填写群号列表，作为 allowlist。
- `max_messages`
  - 最多注入多少条公开群上下文。
- `max_chars`
  - 最多注入多少字符，避免 prompt 过长。

## 双 bot 边界

- 只桥接公开群聊上下文，不区分天使或恶魔独立记忆。
- 当前 bot 的身份仍由事件 `self_id` 和回复风格插件决定。
- 本插件只提供公开上下文，不负责调度；即使调度层安排代班/接力，当前 bot 也只能用自己的身份处理，不能冒充另一个 bot 发言、认错或解释。

## 数据与安全边界

- 只读取公开群上下文文件。
- 不读取私聊、token、QQ 登录态、数据库密钥或运行日志。
- 星环群的领域提示只是额外提示，不作为桥接范围限制。
