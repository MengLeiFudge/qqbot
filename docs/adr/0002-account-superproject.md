# ADR-0002：单仓维护与官方运行包

状态：Accepted

四个 QQ 账号保留独立运行目录及各自配置、进程、虚拟环境、数据和端口。QQBot 负责账号编排、自研插件、NapCat 和框架版本清单。各框架使用固定官方稳定 Release 源码归档在本机部署。

插件的同类实现由 `plugins/` 统一维护，以清单和少量覆盖保留各实例的差异。部署把自研源码同步到各框架约定的目录，实例各自管理市场插件和实际配置。

这个结构把插件提交和框架升级从原有的多仓分支与指针流转中拆开。官方版本升级在主仓审查一个版本变更，由安装器替换本机框架文件。账号顺序、就绪检查与数据隔离继续由各自入口负责。

操作说明见 [框架与插件部署](../framework-deployment.md)。
