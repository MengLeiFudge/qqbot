# ADR-0003：云栖迁到 MaiBot

状态：已决定，待迁移

云栖使用独立的 MaiBot 实例。在普通群聊和私聊中，由 MaiBot 的原生聊天流程判断何时接话和怎样回复，保留云栖的人设与会话边界。固定指令由 MaiBot 插件承接，云栖统一负责现有固定指令、群务和共享数据。迁移完成后，自研机器人插件只维护 MaiBot 实现。

涉及代码修改、构建等复杂任务时，可以通过插件把任务交给 Pi，并把执行结果带回 QQ。QQ 侧负责收集需求、关联发起会话和呈现结果，执行权限由任务授权决定。Pi 桥接可以沿用已有的主人私聊确认和结果回传。

切换时核对云栖的常用指令、业务存档、群文件发布及共享 DSP 检索。共享 DSP 保留一个向量库和现有本机检索接口。实际启用的框架及账号仍按部署清单读取，切换验收后归档 AstrBot 运行态和插件实现。 [现行账号](../bot-roles.md) · [维护入口](../framework-deployment.md)
